一个用于学习 C++ 服务端工程化流程的跨平台 HTTP 服务。

HTTP 能力

支持 GET、HEAD、POST，请求头解析、基础 body 读取和 Keep-Alive。

静态资源

工程流程

配置、日志、测试、文档和压测记录会随开发过程持续补齐。
